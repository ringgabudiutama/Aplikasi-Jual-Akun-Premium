# Folder Foto

Taruh file foto asli Desa Tebel di sini. Nama file yang sudah dipasang di kode:

- `hero-desa.jpg` → foto utama di hero beranda (rekomendasi ukuran minimal 1600x900px, landscape)
- `hero-desa-2.jpg` → foto ke-2 di hero beranda (bergantian otomatis tiap 6 detik)
- `hero-desa-3.jpg` → foto ke-3 di hero beranda (bergantian otomatis tiap 6 detik)
- `about-1.jpg` → foto besar di section "Tentang Kami" (collage kanan atas)
- `about-2.jpg` → foto kecil di section "Tentang Kami" (collage kiri bawah)
- `galeri-1.jpg`, `galeri-2.jpg`, `galeri-3.jpg`, `galeri-4.jpg` → foto di section galeri beranda
- `testimoni-1.jpg` → foto warga di section testimoni
- `sejarah-desa.jpg` → foto di halaman Profil Desa, tab Sejarah

Cukup timpa (replace) nama file di atas dengan foto asli kamu, format JPG/PNG/WebP. Tidak perlu ubah kode lagi karena nama filenya sudah dipanggil otomatis dari `src/pages/public/Home.jsx`.

Kalau file belum ada, bagian itu akan tetap tampil pakai ilustrasi bawaan (tidak error/patah).
